# FlightFieldModule — the flight field

The field of rocks between two stations and the ore broken rocks drop. Read the [root AGENTS.md](../../../../AGENTS.md) first (game, rules, module map). Change this module's description here, not in the root file.

## Assembly
- `Features.FlightFieldModule.Contracts` (layer 1; references: NetworkModel): `FlightFieldModule/Contracts/`: the breakable rock contracts `FieldRockId`, `FieldRockDescription`, `FieldRockDestroyed`, `IFieldRockQuery`, `IFieldRockBreaker`, `IFieldRockEvents`, the peer query `IPeerFieldRockQuery` (every peer, over the published field), and the ore contracts `FieldOreId`, `FieldOreDescription`, `IFieldOreQuery` (every peer, the server included), `IFieldOreCollector`, `FieldOreCollectResult`, `FieldOreCollected`, `IFieldOreEvents`, so the ship, the weapons, the shop and the sonar use them without referencing the field module.
- `Features.FlightFieldModule` (layer 2; references: Matrix, Zenject, Contracts, FlightFieldModule.Contracts, WeaponModule.Contracts, EffectPool, NetworkModel, Mirror, DebugModule.Contracts): the flight field model and its generation in pure C#, the `LiveField` model, the server service and the local building; it does not reference the ship module, the run talks to it through the Contracts; its editor tools are `Features.FlightFieldModule.Editor`.

## Known limits
- **Ore** is a sphere in the data; the crystal is look only. A client places a hooked piece at its own ship, which it shows a
  moment behind the server, so on a client a piece may vanish a little before or after it touches the ship it shows.
  The ore and the harpoon are checked on the host by `LoopSmokeOreCheck` and with a real second client by
  `CoopClientHarpoonTest` (see [Tests/Coop](../../Tests/Coop/AGENTS.md)).
- The field has no "left the field" event.
- A host and a real second client seeing the same field number, seed and placement count is checked by
  `CoopTwoProcessTest` (see "Two-player test" in [Tests/Coop](../../Tests/Coop/AGENTS.md)); the same field after a world shift in flight is covered only by the
  design (one placement list, the origin in the model, pads-like shift of Mirror objects) and by the host checks of
